# Cortex Priority Pivot

- Status: Active
- Date: 2026-04-26

## Call

Fitness footer-owner adoption is treated as the latest clean proof step.

The immediate ATLAS root follow-up is the Cortex-side catch-up for that tranche so the existing proof rail is not left dirty.

After that catch-up, Cortex build-out becomes the primary stack rail.

## Scope Rule

This pivot does not authorize broad stack cleanup.

Current priority is:

1. keep the active proof rail clean with the smallest required ATLAS/Cortex catch-up
2. specify the Cortex MVP surface
3. build the smallest useful Cortex kernel for rail state, context assembly, worker planning, proof interpretation, and receipt drafting

## Boundary Reminder

The pivot does not change owner truth:

- Fitness keeps product UI truth
- Playbook keeps governance truth
- `_stack` keeps orchestration and enforcement truth
- Lifeline keeps receipt and approval truth
- Cortex remains the AI interpretation, context, and proof layer

## Failure Mode

Do not treat "Cortex is now primary" as permission to normalize unrelated stack debt or reopen paused product lanes without a direct Cortex MVP reason.
