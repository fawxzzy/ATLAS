## Cortex Agent Contract Model

Every shadow agent must map back to one governed repetition family and freeze:

- `agent_name`
- `trigger_family`
- `stable_inputs`
- `proof_artifact_expectation`
- `fallback_path`
- `owner_boundary`
- `non_claim_boundary`

The contract is incomplete if any one of those fields is still implicit.

## Rule

`Cortex Follows Governed Repetition`

Cortex agents may only be introduced from already-governed repetition families with explicit trigger, input, proof, fallback, and owner-boundary truth.

## Pattern

`Contract-First Agent Shadowing`

Before an agent executes real work, define its contract against the repetition ledger and let it shadow the workflow without claiming production authority.

## Failure Mode

`Agent Premature Entanglement`

If Cortex agents are introduced before contract and boundary truth are frozen, they become a new drift surface rather than a reduction in operator load.

## Blocked Or Non-Admissible Agent Families

These families remain blocked from honest shadowing or authority:

- fresh live proof capture through the frozen bridge path
- final deploy judgment

- doctrine admission
- destructive cleanup or secret-handling approval
- ambiguous visual or acceptance-criteria review

Why they stay blocked:

- they still depend on human judgment, approval gates, or the frozen external/session defect
- shadowing them too early would misclassify operator authority as agent capability
