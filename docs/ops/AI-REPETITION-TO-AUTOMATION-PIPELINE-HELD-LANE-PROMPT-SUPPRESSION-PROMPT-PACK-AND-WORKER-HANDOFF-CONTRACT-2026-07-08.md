## Worker Objective

The future worker implements a deterministic read-only ATLAS-root classifier that decides whether a generic continuation prompt should be suppressed because root is already held.

It should suppress only when all of these facts are true:

- root is clean or has no root-owned mutation requirement
- validation has `critical=0 error=0`
- selector posture is held or has no immediate executable root packet
- planner exposes no safe selected packet
- no exact operator-selected packet is present
- no routed worker reconciliation is pending
- owner-lane fallback is forbidden by root scope lock
- no external proof is supplied that materially changes the held state

The helper must never be a final authority for receipts, validation verdicts, release readiness, marker output, owner-repo readiness, protected proof, workflow dispatch, deploys, secrets, or PR approval.

## Exit-Code Policy

- `ok`: exit `0`
- `allow`: exit `0`
- `suppress`: exit `0` by default
- `suppress` with `--strict`: nonzero
- `blocked`: nonzero
- `internal_error`: nonzero

The non-strict `suppress` case is advisory so an operator-facing report can explain why continuation was stopped without making a clean held state look like a runtime failure.

## Suppression Triggers

The helper should emit `status=suppress`, `decision=suppress_continuation`, and `safe_to_continue=false` when:

- root and validation are clean
- selector action is held or no-immediate-root-packet
- planner has no safe selected packet
- exact packet availability is false
- no operator-selected packet is supplied
- owner-lane fallback is forbidden
- no validation cleanup or worker reconciliation route is pending

## Suppression Non-Triggers

The helper must not suppress when:

- planner names an exact safe packet
- the operator supplies a bounded packet name
- validation has a critical or error cleanup path
- a worker or implementation-readiness reconciliation packet is pending
- root branch/parity or projection freshness needs root-owned hygiene
- external proof materially changes a held blocker
- a committed manifest names an exact next package that is not already stale or completed

## Owner-Lane Fallback Boundary
