## Exact Command Purpose

`stack receipt package <lane>` exists here to render one bounded draft-only receipt skeleton for a current lane story from durable ATLAS truth.

Its purpose is limited to:

- reading the current lane posture exactly
- reading the current marker and restart surfaces that bound the lane story
- optionally citing one bounded same-story receipt context when the draft skeleton needs exact next-package or hold reasoning support
- emitting one draft-only receipt skeleton with consistent section structure and explicit stop-condition labeling
- returning fail-closed when the source surfaces disagree or the draft package cannot be supported from current durable truth

It does not exist to:

- ratchet markers
- finalize receipt content
- imply doctrine admission
- imply deploy, publication, or owner-repo readiness
- replace decisive receipts or human review with generated wording
