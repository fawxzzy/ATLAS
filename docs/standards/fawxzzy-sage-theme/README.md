# Fawxzzy Sage Theme

Versioned source of truth for the cross-app Fawxzzy theme.

Files:
- `fawxzzy-sage-theme.css`
- `fawxzzy-sage-theme.ts`
- `fawxzzy-sage-mapping.md`
- `fawxzzy-sage-preview.html`

Use this folder as the canonical tracked reference. The mirrored copy under `packages/prebuilt/fawxzzy-sage-theme/` is a local prebuilt export for drop-in use.

Direction:
- dark forest black-green base
- dusty sage text and light sage highlights
- restrained earth undertones separated from the green layer
- premium ambient motion with wisps, glow blobs, particles, and a soft pulse
